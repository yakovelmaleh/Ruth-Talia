# Ruth Talia Couture website

This workspace keeps every iteration separate so a working version is never overwritten.

## Versions

| Version | Location | Purpose |
|---|---|---|
| v1 | `versions/v1-static/` | Original standalone HTML concept |
| v2 | `versions/v2-backend/` | Backend-driven, configurable storefront |
| v3 | `versions/v3-gallery-calendar/` | Multi-image products, gallery, Ruth-managed calendar, and email notifications |
| v4 | `versions/v4-swipe-gallery/` | Two-image minimum and smooth native swipe carousels for products and gallery |
| v5 | `versions/v5-infinite-booking/` | Seamless circular carousels and appointment booking limited to Ruth's open slots |
| v6 | `versions/v6-calendar-card-swipe/` | Triple-copy infinite carousels, swipeable product cards, and clickable availability calendar |
| v7 | `versions/v7-carousel-schedule/` | Repaired transform carousels and automatic 60-minute Sunday–Thursday scheduling |
| v8 | `versions/v8-continuous-clickable/` | Protected continuous loops, clickable selling images, and proportioned booking calendar |
| v9 | `versions/v9-modular-insights/` | Eight products, reliable image opening, filtered slot reasons, responsive polish, and modular visitor insights |
| v10 | `versions/v10-hebrew-product-rail/` | Four-at-a-time product rail, reliable controls, bilingual admin, optional access protection, and polished bottom insights |
| v11 | `versions/v11-soft-rail-mobile-contact/` | Softer product rail, 320px contact fit, Facebook configuration, and clearer visitor-origin insights |
| v12 | `versions/v12-footer-icons-clean-arrows/` | Footer contact icons and transparent collection navigation arrows |
| v13 | `versions/v13-stable-server-gallery-rail/` | Persistent npm start, smaller footer icons, and a soft paged Gallery rail |
| v14 | `versions/v14-micro-footer-icons/` | Extra-small, lighter footer contact icons |
| v15 | `versions/v15-relative-footer-icons/` | Text-relative footer icons with smaller mobile scaling |
| v16 | `versions/v16-inline-contact-icons/` | Simple inline contact symbols followed by footer text |
| v17 | `versions/v17-refined-social-icons/` | Wider footer spacing and refined letter-sized social marks |

Start with `versions/v2-backend/README.md` for setup, configuration, catalog editing, and architecture details.

For future redesigns, copy the latest version into a new folder such as `versions/v3-checkout/`. Do not edit an older version in place.
